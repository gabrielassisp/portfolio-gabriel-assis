# Gabriel Assis — Portfólio de Dados

Portfólio profissional com estudos de caso de engenharia de dados, automação, SQL e Power BI.

## Conteúdo

- Pipeline de dados do Portal da Transparência (pasta `projetos/transparencia-data-pipeline`): Airflow, dbt, BigQuery e Terraform, com código aberto.
- Lakehouse com GCP e Databricks: cópia revisada para demonstração.
- SQL aplicado a vendas e reconexões: contexto e regras de negócio.
- Três dashboards Power BI com dados fictícios e projetos para download.

## Executar localmente

Abra `index.html` ou sirva esta pasta com um servidor HTTP estático. O site usa HTML, CSS e JavaScript, sem etapa de compilação.

## Publicar no GitHub Pages

Em Settings → Pages, selecione Deploy from a branch, branch `main`, pasta `/ (root)`.
